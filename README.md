# schoolmedia

Animations and videos for my DTU course notes in Notion. Generated with Manim.

Layout: `<course>/weekNN/` holds the rendered MP4s and the `scenes.py` that produced them.
Render a scene with `manim -qm --format mp4 scenes.py <SceneName>` from that folder.
